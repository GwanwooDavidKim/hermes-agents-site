Privacy Policy

Last updated: 2026-11-17

Hermes Agents is a personal automation app used only by its owner. It accesses Google user data only from the owner's own Google account, with the owner's explicit consent.

Data accessed

Google Drive file metadata and, when needed for classification, limited file content in the owner's Drive.

Use

Data is used solely to organize the owner's files (suggesting names and folders, moving files after approval) and to deliver requested files to the owner's own tools. Data is not sold, shared with third parties for advertising, or used for any other purpose.

Storage and security

Access tokens are stored on the owner's private server with restricted file permissions. The owner can revoke access at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
